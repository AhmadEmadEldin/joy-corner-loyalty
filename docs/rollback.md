# Rollback

Rollback options:

- Firebase Hosting: roll back to the previous Hosting release in Firebase Console.
- Firebase Functions: redeploy the previous Git commit.
- Firestore staff roles: restore the previous `users/{uid}` document values from audit history.
- Google Sheets: restore from Google Sheets version history.
- Neon: restore from Neon backup/branch if enabled.

Never rollback by deleting financial rows. Use reversals, refunds, cancellation, archive, or restore records.
